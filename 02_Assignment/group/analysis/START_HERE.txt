Assignment 3 complete R analysis

Start with analysis_report.html (Chinese findings, figures and linked result tables).
The report covers Parts 1-4. No PowerPoint slides are produced.

Reproduce from a terminal:
  Rscript --vanilla /absolute/path/to/group/analysis/run_analysis.R
  Rscript --vanilla /absolute/path/to/group/analysis/verify_results.R

RStudio alternative:
  Set the working directory to this analysis folder.
  source("run_analysis.R", encoding = "UTF-8")
  source("verify_results.R", encoding = "UTF-8")

Requirements: R with the recommended package cluster. Base R handles the rest.
This project does not install packages or change the original CSV.
The source must stay at ../Group_presentation.csv relative to this folder.

R/00_helpers.R: output, effect-size, robust-inference and reporting helpers
R/01_data_eda.R: data audit and univariate/bivariate analysis
R/02_clusters.R: k-means, profiles and sensitivity checks
R/03_models.R: cross-validation, regression and diagnostics
R/04_report.R: findings report generated from the actual output

tables/: detailed CSV outputs, including hypotheses/tests and recommendations
plots/: PNG figures for later presentation preparation
models/: fitted models and text output
data/: derived analysis data with row references and cluster membership
logs/: run environment and independent verification

Do not equate the recorded, formula-derived CLV with observed future value.
Do not interpret regression coefficients or cluster differences as causal effects.
Report test metrics from the training model, not the all-data refit.
